# QuoteUpdateStateType

Possible values for the state of the quote that the customer sets by an update: accepted or refused for an approved quote within its validity period, cancelled to withdraw the quote before it is accepted or refused.
The other states are set only by the PSS or the provider.

| Field | Type | Format | Required |
| ------- | ------- | ------- | --- |
| QuoteUpdateStateType | string | oneOf[accepted, refused, cancelled] | No |
